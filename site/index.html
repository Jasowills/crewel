How it works

Three commands. You never assign, tick, or merge by hand — the lead does.

1
crewel init
Wizard asks team size, which agents and how many, and picks the orchestrator. Writes crewel.json.
2
crewel
Launches every pane at once — real PTYs, lead focused at 58% left, teammates tiled right. ConPTY on Windows, forkpty on macOS.
3
prompt the lead
Add a login flow per docs/spec.md — the lead decomposes into tickets, delegates round-robin, handles needs-clarification, reviews, merges. You watch the board.

The roster

Genuinely mixed teams — not locked to one vendor. One adapter file adds another agent type.

ADAPTER · 01

OpenCode

Primary daily driver, held to the highest reliability bar. First adapter built.

ADAPTER · 02

Claude Code

Headless -p --output-format json, typed api_retry telemetry.

ADAPTER · 03

Codex

exec --json with output-schema enforcement, sandboxed workspace writes.

ADAPTER · 00

Mock

Deterministic dry-runs for CI and tests. No LLM required.

Built for senior teams

Tickets carry status, assignee, dependencies, acceptance criteria. Pushback is protocol, not hope.

ISOLATION

Sacred main

Every teammate works crewel/{team}/integration + per-teammate branches. Main is touched only by the lead’s close-out PR.

NOTIFICATIONS

Live, not polled

fs.watch pushes board, mail and jason.log the moment they change. The board above is the product.

RESILIENCE

Degrades gracefully

Interrupt, stall watchdog, rate-limit auto-pause, freeze after 3 failures. Worktrees are never auto-deleted.

Your crew is boarding.

One install. One prompt to the lead. Human-readable state under .crewel/ — no daemon, no dashboard required.
